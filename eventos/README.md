# Carpeta `eventos/`

Aquí viven los contratos **firmados** (un fichero Markdown por evento).

- Si el fichero no está en esta carpeta de `main`, **no cuenta** para la tienda.
- Mientras negociáis, trabajad en un Pull Request. No mezcléis borradores sueltos en la raíz del repositorio.

## Cómo crear un contrato

1. Copiad [`../PLANTILLA-EVENTO.md`](../PLANTILLA-EVENTO.md).
2. Mirad el ejemplo relleno: [`EJEMPLO-como-rellenar.md`](EJEMPLO-como-rellenar.md) (**no es un contrato real**; no lo implementéis).
3. Guardad el fichero aquí con el nombre del evento, por ejemplo `ucjc-descubrimiento-anadir-al-carrito@1.md`.
4. Abrid un Pull Request. El profesor fusiona a `main` cuando el estado pase a `firmado`.
